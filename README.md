## ✨ Fitur-Fitur di Peta Palu

1. ⚡ **Peta Pemadaman Listrik PLN Sulteng**: Monitoring status padam/menyala live menurut waktu WITA, estimasi durasi, dan fitur *Cek Rumah Saya* (GPS).
2. ☕ **Peta Coffeeshop & Resto**: Direktori jujur 975+ titik kuliner se-Kota Palu tanpa rating bias, filter jam buka live, dan filter brand.
3. 🖨️ **Peta Fotocopy & Percetakan**: Direktori 220+ tempat fotocopy kilat, digital printing banner, 3D print, dan penjilidan.
4. 🏛️ **Peta RTRW Kota Palu**: Rencana Tata Ruang Wilayah 2021–2041 berdasarkan Perda No. 2/2021.
5. 🏠 **Dashboard Awal**: Pop-up interaktif pemilihan layanan kota dengan latar belakang peta *freeze*.
